카페 데이터 동기화 / 백업

카페(jusumcafe)에서 "정산 전송"을 누르면 잔액뿐 아니라 그동안의 주문/지출 내역도 자동으로 같이 들어와요. 이 버튼은 정산 전송 전에 미리 확인하고 싶을 때나, 자동 동기화가 실패했을 때 수동으로 다시 가져오는 용도예요. 여러 번 눌러도 이미 들어온 내역은 다시 추가되지 않아요.

📊 엑셀로 내보내기 (전체내역·구매지출·수입·카페동기화·정산 시트별로)

실수로 내역을 지웠거나, 카페 쪽 내역이 분명히 있는데 리스트에 안 보이는 경우 — 위 버튼은 "마지막으로 가져온 지점 이후"만 보기 때문에 이미 지나간 날짜 건은 다시 못 가져와요. 아래 버튼은 카페의 전체 주문/지출 기록을 처음부터 다시 훑어서, 지금 빠져있는 것만 골라 복구해요. 이미 있는 내역은 건드리지 않고, 여러 번 눌러도 안전해요.

🤝 카페 → 청년부 후원/이체

카페 재정과 청년부 재정은 이제 완전히 분리된 두 계좌예요. 카페 쪽 현금/계좌가 실제로 청년부로 넘어갈 때(후원·이체)만 여기서 기록하세요 — 카페 계좌에서는 지출로, 청년부 계좌에서는 수입(카페 후원금)으로 자동으로 같이 기록되고, 전체 합계는 그대로예요. (카페 돈으로 청년모임 식사비 등을 식당에 직접 결제한 경우는 여기가 아니라 평소처럼 "구매 지출 입력"에서 카페 쪽으로 기록하면 돼요 — 현금이 청년부 손으로 넘어온 게 아니니까요.)

실제 잔액 기준점 다시 맞추기 (현금 / 터치앤고 / 은행)

대시보드의 "실제 잔액 구성"은 평소엔 자동으로 계산돼요. 가끔 현금/계좌를 직접 세어봤는데 숫자가 안 맞을 때만, 여기서 그 시점 기준으로 다시 맞춰주세요. 이 폼은 청년부 계좌 기준이에요 — 카페 쪽은 카페 관리자 페이지의 "정산 전송" 버튼을 누르면 카페 계좌에 자동으로 들어오고, 그동안의 주문/지출 내역도 같이 동기화돼요.
